Automated Parking System

An automated parking system built with ESP32 and Python Django. It gives drivers real-time parking guidance, lets them reserve a slot, and handles payment. It is designed to scale with smart city integration, EV charging, predictive analytics and stronger security, to improve urban mobility and the user experience.

A system that keeps a constant watch on street lights and flags the moment one fails, so the control room knows exactly which pole needs repair.
